# Contributing to Express Toll Pass

First off, thank you for considering contributing to Express Toll Pass! It’s people like you that make this tool great for commuters and fleet managers alike.

---

## Contribution Guidelines

To maintain code quality, ensure the longevity of the application, and keep the user experience seamless, we ask that all contributors follow these basic guidelines:
* Write clean, readable, and well-documented JavaScript (React).
* Ensure standard UI styling consistency by using the dedicated component CSS files.
* Test your changes locally before submitting a Pull Request.

---

## How to Contribute

1. **Fork the Repository:** Create your own copy of this project by clicking the "Fork" button at the top of this page.
2. **Clone the Fork:** Download your fork to your local machine.
3. **Create a Branch:** Create a feature branch for your changes:
   ```bash
